# Red Social API

API REST para una red social construida con Node.js, Express y MongoDB. Este proyecto forma parte de mi porfolio de estudiante y se desarrolla paso a paso con foco en buenas practicas.

**Stack**
- Node.js
- Express
- MongoDB
- Mongoose
- JWT (jwt-simple)
- CORS
- Multer

**Requisitos**
- Node.js 18+
- MongoDB en local (por defecto en `mongodb://localhost:27017/red-social`)

**Instalacion**
1. `npm install`
2. `npm start`

**Scripts**
- `npm start`: inicia el servidor con Nodemon (`index.js`).

**Estructura**
- `index.js`: punto de entrada del servidor.
- `database/connection.js`: conexion a MongoDB.

**Endpoints**
- `GET /ruta-prueba`: devuelve un JSON de prueba.
